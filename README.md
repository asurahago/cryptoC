## 🪙

`cryptoC` — учебная account-based криптовалюта. поверх блокчейна можно строить приложения. мы повторяем архитектуру ethereum в упрощённом виде, чтобы понять: как рождается блок, откуда берутся монеты, почему нельзя подделать транзакцию и как сеть хранит балансы.

моя цель - понимание блокчейн технологий.

## как это работает

### ключи: ed25519

у каждого участника есть пара ключей: это асимметричная криптография: из приватного ключа **математически** вычисляется публичный, но не наоборот.

### подпись: доказательство авторства

```
tx = {sender, receiver, amount, nonce}
hash = sha256(tx)
signature = ed25519_sign(hash, private_key)     ← алиса
verify(public_key, hash, signature) == true     ← сеть
```

изменить `amount` в транзите - хеш изменится, и старая подпись перестанет сходиться. сеть отвергнет транзакцию.

### хеш вектора транзакций

```
                   merkle_root
                        │
              ┌─────────┴─────────┐
           h(AB)                 h(CD)
          ┌──┴──┐               ┌──┴──┐
        h(A)  h(B)            h(C)  h(D)
         │     │               │     │
        tx1   tx2             tx3   tx4
```

каждая транзакция хешируется, пары склеиваются и хешируются снова, пока не останется один хеш — **merkle root**. он записывается в заголовок блока. если поменять **хоть один символ** в любой tx — merkle root станет другим, блок невалиден.

### coinbase

в генезис-блоке и в каждом новом блоке есть транзакция от отправителя `"COINBASE"` — это **эмиссия награды майнеру**. это не перевод от кого-то, а создание монет по правилам протокола. когда supply достигнет потолка — coinbase перестанет создаваться. это и есть дефицит, который делает монету ценной.
